# 交通标志与行人车辆检测系统

> YOLOv8 目标检测｜数据处理｜模型评测｜软件功能测试｜PyQt5

## 项目简介

本项目基于 **YOLOv8** 实现交通场景目标检测桌面应用，支持图片、本地视频和摄像头实时检测，可识别行人、机动车及交通标志等目标。

本人项目角色为**数据处理与测试**，主要负责数据集筛选、清洗、标注校验、数据增强、模型效果评测、软件功能测试、缺陷现象记录及项目文档归档。

## 我的主要工作

### 1. 数据集处理
参与道路图像数据集筛选、样本清洗和分类，对标注数据进行检查与校验。针对小目标、目标遮挡、样本分布不均衡等情况，参与数据增强和样本整理。

### 2. 模型实验与效果评测
收集整理 YOLOv8 多轮训练实验指标，对 **mAP@0.5、Recall、各类别 AP、误检、漏检**进行分析比较。

重点记录小目标、遮挡等复杂场景下的模型缺陷，为模型调优提供实验依据。

### 3. 软件功能测试
对图片检测、图片批量检测、视频检测、摄像头检测、参数调整、结果归档、结果保存、视频推理与导出、目标信息展示等功能进行测试验证。

### 4. 问题定位与文档
围绕模型误检、漏检以及视频处理等问题进行现象记录和测试验证，整理实验结果、测试材料和项目文档。

## 技术栈

- Python 3.9
- PyTorch
- Ultralytics YOLOv8
- OpenCV
- Pillow
- NumPy
- PyQt5

核心技术：YOLOv8 模型推理、图像预处理、目标框解析、Qt 信号槽、QThread 多线程、实时视频流处理、模型指标评测。

## 核心功能

- 支持图片、本地视频、摄像头三种数据源
- 识别行人、机动车、交通标志
- 动态调整 Confidence 与 IoU/NMS 阈值
- 展示检测框、类别、置信度、目标数量、推理耗时
- 支持图片批量检测
- 支持检测结果保存
- 长视频采用异步任务与进度展示
- 支持目标筛选查看

## 系统架构

```text
UI 交互层
    ↓
Qt 信号 / 槽
    ↓
业务逻辑层
    ↓
YOLOv8 模型推理
    ↓
结果解析与图像处理
    ↓
UI 渲染 / 数据统计
    ↓
本地结果保存
```

系统分为 UI 交互层、业务逻辑层和数据资源层，实现功能解耦。

```bash
pip install ultralytics torch opencv-python pillow numpy PyQt5
```

## 运行方式

将训练完成的 `best.pt` 放置到 `models/`，然后运行：

```bash
python MainProgram.py
```

进入 GUI 后可选择图片、视频或摄像头数据源执行检测。
