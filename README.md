# 交通标志与行人车辆检测系统

> YOLOv8 目标检测｜数据处理｜模型评测｜功能验证｜AI 项目实践

基于 YOLOv8 的交通场景目标检测桌面应用，支持图片、本地视频和摄像头实时检测，可识别行人、机动车及交通标志等目标。

本人在项目中主要负责**数据处理、场景分析、模型效果评测、功能验证、问题定位及项目文档整理**，围绕实际使用场景对模型效果和软件功能进行分析与验证。

---

## 项目简介

本项目基于 **YOLOv8** 实现交通场景目标检测功能，并结合 PyQt5 构建桌面端应用。

系统支持多种数据源，包括：

- 图片检测
- 图片批量检测
- 本地视频检测
- 摄像头实时检测

能够对交通场景中的：

- 行人
- 机动车
- 交通标志

进行目标识别，并展示检测框、类别、置信度、目标数量及推理耗时等信息。

项目重点围绕**数据质量、模型效果、软件功能和实际使用场景**开展实验与验证。

# 我的主要工作

## 1. 场景与需求分析

围绕道路场景下行人、车辆及交通标志自动识别需求，参与梳理图片检测、批量检测、视频检测及摄像头检测等核心使用场景，明确不同场景下的功能与效果验证重点。

根据不同数据源和使用方式，关注检测准确性、结果展示、处理效率及结果保存等功能表现，为后续测试与效果评估提供验证依据。

## 2. 数据处理与问题分析

参与道路图像数据集筛选、样本清洗、分类及标注校验，对数据质量进行检查。

针对：

- 小目标
- 目标遮挡
- 样本分布不均衡

等情况，参与数据增强和样本整理。

结合多轮模型实验结果，对不同场景下的检测效果进行分析，重点关注：

- 漏检

通过实验数据和检测结果定位模型存在的问题，为后续数据优化和模型迭代提供依据。
