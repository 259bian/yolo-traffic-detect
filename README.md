# 交通标志与行人车辆智能检测系统

> Python智能检测应用｜PyQt5桌面系统｜YOLOv8目标检测｜模型效果验证

---

## 项目简介

本项目是一套基于 Python 开发的交通场景智能检测应用系统。

系统结合 PyQt5 构建桌面端交互界面，并集成 YOLOv8 目标检测模型，实现对道路场景中行人、机动车以及交通标志等目标的自动识别。

系统支持：

- 图片检测
- 图片批量检测
- 本地视频检测
- 摄像头实时检测

检测过程中能够展示：

- 目标检测框
- 目标类别
- 置信度
- 目标数量
- 推理耗时

并支持检测结果保存和结果归档。

本人在项目中主要负责：

- 系统功能设计与验证
- 数据处理与样本分析
- 模型效果评估
- 功能测试与问题定位
- 项目文档整理

围绕实际交通应用场景，对系统功能完整性和模型检测效果进行验证。

# 系统功能

## 1. 图片目标检测

支持用户上传单张图片进行检测。

主要流程：

```
图片输入
    ↓
YOLOv8模型推理
    ↓
目标结果解析
    ↓
检测框绘制
    ↓
结果展示
```

输出内容：

- 检测目标类别
- 目标位置
- 置信度
- 检测数量


---

## 2. 图片批量检测

支持批量导入图片进行自动检测。

功能包括：

- 批量读取图片
- 自动执行检测任务
- 保存检测结果
- 生成检测记录


---

## 3. 视频目标检测

支持本地视频文件检测。

实现：

- 视频读取
- 视频帧解析
- 帧级目标检测
- 检测结果实时展示
- 视频结果导出


---

## 4. 摄像头实时检测

支持调用摄像头进行实时检测。

主要功能：

- 摄像头视频流读取
- 实时目标识别
- 检测结果展示
- 实时状态更新


---

## 5. 参数调整

支持动态调整模型检测参数：

- Confidence 阈值
- IoU 阈值

方便观察不同参数条件下模型检测效果。
